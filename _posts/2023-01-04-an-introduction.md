title: An Introduction
---
“Nixer” is an ultra-minimalistic, barely functional Jekyll theme, that only uses default colors and tag selectors, making it a classless CSS design. Compared to [“Nix”](https://jekyll-theme-nix.michaelnordmeyer.com/), it doesn’t disclose anything on the website about authors or blog names.

The feature set is explained in the [readme on GitHub](https://github.com/michaelnordmeyer/jekyll-theme-nixer).
